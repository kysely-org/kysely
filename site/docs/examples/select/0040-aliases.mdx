# Aliases

You can give an alias for selections and tables by appending `as the_alias` to the name:

```ts twoslash playground
const persons = await db
  .selectFrom('person as p')
  .select([
    'first_name as fn',
    'p.last_name as ln'
  ])
  .execute()
```
