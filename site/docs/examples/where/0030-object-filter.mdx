# Object filter

You can use the `and` function to create a simple equality
filter using an object

```ts twoslash playground
const persons = await db
  .selectFrom('person')
  .selectAll()
  .where((eb) => eb.and({
    first_name: 'Jennifer',
    last_name: eb.ref('first_name')
  }))
  .execute()
```
