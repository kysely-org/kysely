# Running on Deno

Kysely is published to [JSR](https://jsr.io/@kysely/kysely) as `@kysely/kysely`. Deno can import it directly. For example, the built-in PostgreSQL dialect can execute queries using the `pg-pool` npm driver:

```ts
import { Generated, Kysely, PostgresDialect } from 'jsr:@kysely/kysely'
import Pool from 'npm:pg-pool'

interface Database {
  person: {
    id: Generated<number>
    first_name: string
    last_name: string | null
  }
}

const db = new Kysely<Database>({
  dialect: new PostgresDialect({
    pool: new Pool({ connectionString: Deno.env.get('DATABASE_URL') }),
  }),
})

try {
  const people = await db.selectFrom('person').selectAll().execute()
  console.log(people)
} finally {
  await db.destroy()
}
```

Run this example with `--allow-env --allow-net` and a PostgreSQL connection string in `DATABASE_URL`.

## Compile SQL without a database connection

If you only need to build and compile queries, use `DummyDriver`:

```ts
import {
  DummyDriver,
  Generated,
  Kysely,
  PostgresAdapter,
  PostgresIntrospector,
  PostgresQueryCompiler,
} from 'jsr:@kysely/kysely'

interface Person {
  id: Generated<number>
  first_name: string
  last_name: string | null
}

interface Database {
  person: Person
}

const db = new Kysely<Database>({
  dialect: {
    createAdapter() {
      return new PostgresAdapter()
    },
    createDriver() {
      // You need a driver to be able to execute queries. In this example
      // we use the dummy driver that never does anything.
      return new DummyDriver()
    },
    createIntrospector(db: Kysely<unknown>) {
      return new PostgresIntrospector(db)
    },
    createQueryCompiler() {
      return new PostgresQueryCompiler()
    },
  },
})

const query = db.selectFrom('person').select('id')
const sql = query.compile()

console.log(sql.sql)
```
