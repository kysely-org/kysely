# Running on Deno

Kysely is published to [JSR](https://jsr.io/@kysely/kysely) as `@kysely/kysely`. Deno can import it directly. For example, the built-in PostgreSQL dialect can execute queries using the `pg-pool` npm driver:

```ts
import { Generated, Kysely, PostgresDialect } from 'jsr:@kysely/kysely'
import Pool from 'npm:pg-pool'

interface Database {
  person: {
    id: Generated<number>
    first_name: string
    last_name: string | null
  }
}

await using db = new Kysely<Database>({
  dialect: new PostgresDialect({
    pool: new Pool({ connectionString: Deno.env.get('DATABASE_URL') }),
  }),
})

const people = await db.selectFrom('person').selectAll().execute()
console.log(people)
```

Run this example with `--allow-env --allow-net` and a PostgreSQL connection string in `DATABASE_URL`.

For building and compiling queries without a database connection, see
[Splitting query building and execution](/docs/recipes/splitting-query-building-and-execution).
